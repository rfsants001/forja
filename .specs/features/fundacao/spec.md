# F0 · Fundação

Entregue: monorepo pnpm com `@forja/core` e `apps/web`, TypeScript estrito, Vitest, React/Vite, Dexie e PWA. `pnpm dev` inicia em localhost:5577. O build gera o service worker. IndexedDB v2 guarda dados do usuário e acrescenta medidas com migração aditiva.

O pivô de 10/11/2026 estabeleceu o cliente estático. O planejamento original de Hono, SQLite e Docker foi encerrado no escopo atual. A instalação real da PWA e as atualizações offline integram o aceite do piloto.
